MEGASPORT - ARCHIVOS NUEVOS O MODIFICADOS

Uso:
1. Cierra los servidores del frontend y backend.
2. Extrae el contenido del ZIP dentro de la carpeta principal del proyecto.
3. Cuando Windows pregunte, selecciona "Reemplazar los archivos en el destino".
4. En la carpeta megasport-backend ejecuta: npm install
5. Agrega las variables nuevas a los archivos .env según la guía
   INTEGRACION_CARRITO_Y_SERVICIOS.md.
6. Vuelve a ejecutar backend y frontend con: npm run dev
